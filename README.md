## 🚀 Key Features

* **3D Human Character & Kinetic Hero Canvas:** Built with Three.js, GLTFLoader, Mixamo animation retargeting (`warrior-idle.fbx`, `Backflip.fbx`), procedural mouse/gaze head tracking, and gyroscopic emissive torus rings.
* **5-Waypoint Camera Spline Rail:** Smooth camera waypoint transitions that adapt perspective as the user navigates across scenes.
* **7 Comprehensive Portfolio Pages:**
  1. `Home` (`/`) — Kinetic 3D hero, camera rail, side scene rail, animated KPI counters, architectural pillars, and certification badges.
  2. `Profile` (`/profile`) — Executive background, recognition cards, stats banner, core competencies, toolchain matrix, education, and credentials.
  3. `Philosophy` (`/psychology`) — Interactive mental model widgets (Hick's Law, Doherty Threshold, Miller's Law, Goal-Gradient rollouts).
  4. `Projects` (`/projects`) — 2-column project gallery with ghost index numbers, client context, and measured KPI impacts.
  5. `Experience` (`/experience`) — Career timeline with dynamic scroll progress bar tracking Maven Wave and Stefanini roles.
  6. `Services` (`/services`) — 6 specialized cloud & DevOps offerings and a structured 4-step delivery workflow.
  7. `Contact` (`/contact`) — Validated contact form, availability badge, one-click email copy, and direct mailto triggers.
* **Design System & Typography:** Sora (display headings), Inter (body readability), and JetBrains Mono (code chips and index labels).
* **Dual Theme Engine:** Dark and light modes with custom CSS tokens and glassmorphism.

## 🛠️ Tech Stack

* **Framework:** React 18, TypeScript, Vite
* **3D & Graphics:** Three.js, `@types/three`
* **Motion & Animation:** Framer Motion
* **Routing:** React Router v6
* **Hosting:** Vercel (Production CDN with SPA rewrites)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/MrYashBaghel/yash-baghel-portfolio.git
cd yash-baghel-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
